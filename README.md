# GH Relay - Database Setting Relay Proteksi United Power

Aplikasi database offline untuk setting relay proteksi Gardu Hubung (GH),
dipakai teknisi di lapangan. Navigasi hierarkis: MSS -> MDS -> TDS -> Output.

Dibangun dengan Python + Kivy, di-build lewat Buildozer di Termux (proot Ubuntu).
